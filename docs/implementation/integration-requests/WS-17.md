## 1. Wire Impact Router into `src/backend/main.py`

Per `14-PARALLEL-WORKSTREAMS.md` §2.3 and `15-SHARED-CONTRACTS.md` §12.1, `src/backend/main.py` is Integration-only. WS-17 publishes `router` from `src/backend/routers/impact.py`.

Please add the following during Integration:

```python

from src.backend.routers import impact

# In src/backend/main.py include_router section:
app.include_router(impact.router)
```
